# LWF Eye Drops

**Lazy Witch's Factory** 瞬きのときに出る影や縦線を洗い流す MOD

## モモコ

- 瞬き・半眼のときの影や縦線を消す

（画像: momoko.png）

## 採掘ゴブリン・鍛冶師サラマンダー

- 瞬きのときの縦線を消す

（画像: familiars.png）

## 設定

- キャラクターごとの切り替えは MOD管理ソフトの Config editor（`kiyonakanata.lwfeyedrops.cfg`）
- `Momoko`・`Mining Goblin`・`Blacksmith Salamander` = `false` → そのキャラクターは対象から外れる
- 変更はゲームの再起動後に反映
